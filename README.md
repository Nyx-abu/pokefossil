## 🔍 What is PokéFossil?

PokéFossil is a forensic tool for Pokémon Generation III save files (`.sav`). Instead of editing Pokémon (like PKHeX), it acts as a digital archaeologist to **reconstruct a best-evidence account of the player's journey**.

Have you ever found an old cartridge in a drawer or bought one on eBay and wondered about the journey of the previous owner? PokéFossil digs deep into the save data to recover their timeline, uncover lost "ghosts" of released Pokémon, and verify the legitimacy of their team.

## ✨ Features

- 🕰️ **Journey Estimate**: A best-guess chronological reconstruction of the player's adventure, tracking their captures and Hall of Fame entries with confidence scores.
- 👻 **Ghost Recovery Engine**: When you save the game, a backup block is created. PokéFossil diffs the active save block against the backup block to resurrect Pokémon that were released or overwritten in the last save!
- 🕵️ **Legitimacy Forensics**: A non-binary, 3-tier verdict model (`Verified`, `Uncertain`, `Likely Modified`) based on PID-IV LCRNG correlation testing. It checks Bad Egg flags, checksums, and Method 1/2/4 RNG patterns without issuing false "Hacked" accusations for legitimate wild encounters.
- 📂 **Case File Dashboard**: A beautiful, immersive UI themed as a forensic evidence room. Explore boxes, examine ghosts, and read detailed legitimacy reports.

## 🛠️ How It Works

PokéFossil parses the 128 KB binary `.sav` files directly in your browser. 
It reverse-engineers the **Linear Congruential Generator (LCRNG)** used in Gen III to reconstruct seeds from PIDs, allowing it to mathematically prove if a Pokémon's IVs and PID were generated by the game naturally.

It also leverages the dual-block save system (Block A and Block B) to find "diffs" between the two most recent saves, allowing the recovery of newly deleted data.

## 🔒 Privacy Guarantee

**Zero uploads.** The app runs 100% client-side in your browser. Your save files are never sent to a server. You can even run the web app offline.

## 💻 Tech Stack

- **TypeScript** + **React 18**
- **Vite**
- **Tailwind CSS v4**
- **Zustand** (State Management)
- Pure `ArrayBuffer` and `DataView` parsing (Zero dependencies!)

## 🚀 Getting Started

To run the web app locally:

```bash
git clone https://github.com/yourusername/pokefossil.git
cd pokefossil
npm install
npm run dev
```

Then open `http://localhost:5173` and drag-and-drop your `.sav` file into the Drop Zone!
